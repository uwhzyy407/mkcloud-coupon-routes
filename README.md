## Mkcloud 是什么服务商

Mkcloud 2023 年创建，国人商家，主营跨境专线 VPS，不是普通公网 VPS 商家。产品形态是"单端双独立 IP"：你连接入口 IP（国内某省的运营商入口），机器流量从独立的香港/日本/美国出口 IP 发出。线路方向包括广港 IEPL、深港 IX、沪港 IPLC/IX、沪日 IPLC、沪美 IPLC、福港高防，以及上海 CN2 国内优化产品。

几个对购买决策影响很大的特点：

- 购买需要国内手机号实名认证，支持支付宝。
- 直连款绑定一个省份的 IP 白名单连入，官方明确说这是防机场滥用的措施，适合个人或团队自用。
- 出口仅出不进，不支持外部连入，不能用来做公开网站、邮件接收或游戏服务端。
- 支持月付、季付、半年付、年付，现货通常开通很快，官方口径约 1 分钟。

## 第三方实测数据怎么说

VPS.Dance 测评过广港 IEPL 500GB 套餐，几个数据点：广州入口 TCP ping 平均电信 34ms、联通 33ms、移动 38ms；香港出口到 Cloudflare 延迟 5.7ms、单线程下载 134Mbps，基本跑满 150Mbps 标称带宽；磁盘 I/O 平均约 304MB/s。测评者的总结是"买 IP 送机器"——双独立 IP 是核心价值，流量单价约 ¥0.7–0.8/GB（单向口径），在国内 BGP 专线里属于常见价位。

IP 质量方面要客观：实测出口为 IDC 机房 IP，不同 IP 库的风控评分不一，官方也明确不保证原生、住宅或流媒体解锁。如果业务对 IP 信誉极其敏感，先按官方支持的质量问题退款流程留好测试证据。

## 买前要知道的限制

这些条款直接影响使用预期，下单前建议过一遍：

- 超量后暂停服务，需要自助购买流量重置或工单补差价升级；流量双向统计，预算别按单向习惯估。
- 共享带宽为峰值，不保证持续跑满。
- 升降级都要走工单，降级到更低价格套餐时差价不退。
- 退款仅限质量问题，需提交测试截图，由商家审核判断；开通后不支持更换地域。
- 默认无 SLA 保证，高防参数、售后响应时长等细节需工单确认。
- 直连款仅允许绑定省份的 IP 连入，跨省使用需要先切换白名单。

## 常见问题

**Q：MK-8.8 现在还能用吗？**
A：官方知识库当前展示为全场流量计费产品循环 8.8 折，属于长期挂出的优惠。但 Mkcloud 活动密集，建议结账时实际验证，以购物车核算结果为准。

**Q：历史活动码 MK-NEW、CLOUD-2T-NEW 还能领吗？**
A：不能。官方已标注这些活动码随对应活动结束失效，网上流传的历史折后价不要用来计算新订单。

**Q：广港 IEPL 和沪日 IPLC 怎么选？**
A：端内延迟官方资料为广港 1~2ms、沪日 25~28ms，两者价格档位一致。华南地区用户或对延迟敏感的场景选广港；长三角用户或业务对象在日本方向选沪日。

**Q：月付还是年付划算？**
A：官方确认的沪港套餐季付、年付折算后与月付同价或略低，叠加 MK-8.8 这类循环码后年付优势更明显。但考虑降级差价不退的规则，不确定长期需求就先月付。

**Q：需要什么条件才能买？**
A：国内手机号实名认证（姓名、身份证、手机号一致性验证），支持支付宝付款，月付起步，试错成本可控。
